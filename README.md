## Hey, I’m Tanishq 👋

I’m a software developer who enjoys turning ambitious ideas into useful, polished products. I work across **AI-powered experiences and full-stack applications**, with a particular interest in voice interfaces, agent safety, and the details that make software feel good to use.

### What I’m building

**[XENIO](https://github.com/tanishqnarula12/Xenio)** is my current focus: a voice-first control layer for Hermes Agent, with a desktop interface and explicit approval for sensitive actions. I’m exploring how capable AI assistants can feel natural while keeping people in control.

### Selected projects

| Project | What it is |

| [**XENIO**](https://github.com/tanishqnarula12/Xenio) | Voice-first personal AI, desktop controls, and approval-based tool safety. |
